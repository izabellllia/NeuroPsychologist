# 🧠 NeuroPsychologist — твой ИИ-наставник по ментальному здоровью

## 💡 О проекте

**NeuroPsychologist** — это твой персональный ИИ-компаньон, который помогает:

✨ Осознанно проживать каждый день  
🧘 Разбираться в собственных эмоциях  
🩺 Получать рекомендации по восстановлению  
🛠️ Находить решения в сложных или конфликтных ситуациях  

Создано для тех, кто заботится о себе и своём ментальном здоровье. Особенно актуально для людей, живущих в бешеном ритме, но стремящихся к балансу.

---

## 🚀 Почему это круто?

- **Разгрузи голову в конце дня** - просто ответь на несколько вопросов — нейросеть поможет структурировать мысли, выявить триггеры и подвести итоги без самокопания.
- **Понимание и отчёты** - получай обратную связь и рекомендации, основанные на твоих ответах и общем контексте, без необходимости делиться с другими людьми.
- **Живые данные о себе** - смотри как меняется твоё состояние: настроение, стресс, энергия.

**Ключевой результат**: пользователь должен за ≤ 5 минут в день получить полезный инсайт и конкретные советы.

## Функциональные требования  

### Этап 1 (MVP)

##### 1.1. Функция: Сессия дня
Пользователь отвечает на набор вопросов → ответы отправляются на бэкенд → формируется и отправляется запрос в LLM → LLM возвращает небольшую структуру (оценка дня, 2–3 инсайта,  практических совета) → показываем пользователю.

**User stories**
* Как пользователь, я хочу пройти короткую сессию (≤ 5 минут), чтобы получить ясную оценку моего дня и конкретные советы.
* Как пользователь, я хочу видеть, какие вопросы задают и иметь возможность пропустить вопрос.
  
**Acceptance criteria**
* Пользователь может начать новую сессию с явной кнопкой «Начать сессию».
* Сессия содержит последовательность вопросов; пользователь может ответить текстом/выбрать варианты/оценить по шкале (1–5).
* После отправки всех ответов система показывает загрузчик и затем результат от LLM.
* Результат включает: общую оценку дня (число/метка), краткое резюме (2–3 предложения), 3 конкретных совета по восстановлению.
* В случае таймаута LLM (> 10 сек) показывается дружелюбная ошибка с возможностью повторить запрос.

**UX / UI notes**
* Интерфейс в спокойных тонах (пастель, мягкая типографика), загрузка вопросов one-question-per-screen.
* Подсказки: «Это займет ~3–5 минут».
* Кнопка «Пропустить вопрос» и «Вернуться назад».
* Показывать индикатор конфиденциальности: «Ваши ответы используются только для персональной аналитики».

##### 1.2. Функция: Интерфейс 
Спокойная, минималистичная веб-версия с responsive версткой.

* One-question-per-screen + прогрессбар.
* Экраны: Onboarding (короткий), Start Session, Question Screen, Result Screen, Feedback (оценка полезности).

**Acceptance criteria**
* Прогресс корректно отображается.
* UI-набор цветов согласован с mood-brand (спокойные оттенки); реализовать темную/светлую темы как опцию в будущем.


##### 1.3. Функция: Интеграция с LLM API
Надёжный адаптер между бэком и LLM, с обработкой ошибок и логикой промптов.

* Сервис-адаптер для вызовов LLM API: реализовать retries, таймауты и логирование.
* Два типа вызовов: синхронный (малым объёмом) и асинхронный (для долгих генераций).
* Включить уровень «system prompt» с ролью: «Нейропсихолог, дружелюбный, не даёт медицинских диагнозов, предоставляет общие рекомендации».
Prompt engineering (рекомендации)
* Ошибки LLM обрабатываются и корректно транслируются в UI (человеко-читаемая ошибка).

### Этап 2 Аналитика и редактирование результатов

##### 2.1. Функция: Аналитика (графики)
Визуализация динамики основных метрик: настроение, стресс, энергия

**Метрики и модель**
* По каждой сессии LLM и/или пользователь генерируют/ставят числовые значения:
    * mood (1–5), stress (1–5), energy (1–5)
* Расчёт скользящей средней, недельные/месячные агрегаты.
  
**Acceptance criteria**
* Графики корректно строятся на основе данных.
* Фильтрация работает и быстро отвечает (предел: < 3 сек).

##### 2.2. Функция: Редактирование результатов (корректировка ИИ)

**User stories**
* Как пользователь, я хочу отметить, что оценка ИИ некорректна, и задать свою версию.
  
**Acceptance criteria**
* На экране результата есть кнопка **Не согласен — исправить**.
* После исправления создаётся запись в corrections и UI показывает **Спасибо — мы учтём это**.
* Коррекции используются в будущем: вручную для улучшения промптов и/или как часть supervised dataset.
* Публичные/анонимные опросы для оценки согласия с выводами ИИ.
  

### Этап 3 — оптимизация промптов, тестирование, CI/CD

##### 3.1. Функция: Тестирование и доработка промптов
Коротко: систематическая работа над промптами: A/B тесты, логирование, human-in-the-loop.
**Process**
* Версионирование промптов (git).
* A/B тестирование: разные версии промптов/answer templates показывают разные результаты → track KPIs (полезность, время до завершения, retention).
* Human review: выборочный аудит raw_llm_response + коррекции от пользователей → dataset для доработки.
  
**Acceptance criteria**
* Возможность переключить промпт-версию per rollout (feature flag).
* Сбор метрик сравнений и вывод статистики.

##### 3.2. CI/CD
* GitHub Actions для build/test/deploy.
* Pipeline stages: lint → unit tests → integration tests → deploy to staging → e2e tests → deploy to prod (with manual gate).
* Canary / phased rollout и feature flags для риска LLM-поведения.
